# CS-370-Module-Eight

**Briefly explain the work that you did on this project. What code were you given? What code did you create yourself?**

For this project, I worked on developing an intelligent pirate agent that could navigate a maze and find treasure using reinforcement learning. I was provided with starter code that included the TreasureMaze.py file, which handled the maze environment, and GameExperience.py, which managed the agent's past experiences. The project also included a Jupyter Notebook with some of the code already completed. My main responsibility was to develop and implement the Q-training algorithm (qtrain) using deep Q-learning. This involved training the agent to make decisions, updating the neural network based on its experiences, and adjusting how it learned from rewards and penalties. I also tested and debugged the code to improve the agent's ability to reach the treasure.

**What do computer scientists do and why does it matter?**

Computer scientists develop solutions to problems using technology, programming, and logical thinking. Their work goes beyond writing code because they also design systems, analyze data, troubleshoot problems, and find ways to make technology more efficient. Throughout this course, I learned how artificial intelligence and machine learning can be used to solve problems that would otherwise require constant human decision-making. These skills matter because computer science plays a major role in everything from cybersecurity and networking to automation and healthcare.

**How do I approach a problem as a computer scientist?**

I approach problems by first understanding what needs to be accomplished and then breaking the problem into smaller, manageable pieces. From there, I look at possible solutions, develop a plan, and test my work to see whether it produces the expected results. This course reinforced the importance of experimenting and learning from failures. For example, when working on the pirate treasure hunt project, I had to troubleshoot errors, adjust the Q-learning training process, and evaluate the agent's performance. I learned that getting code to run is only part of the process. It is just as important to understand why something works and how it can be improved.

**What are my ethical responsibilities to the end user and the organization?**

As a computer scientist, I have a responsibility to develop technology that is secure, reliable, and fair to the people using it. This includes protecting user information, reducing bias in AI systems, and making sure software behaves as intended. Organizations also depend on developers to follow security practices, handle data responsibly, and communicate potential risks. One thing this course emphasized is that AI systems can make decisions based on the data and rewards they are given, but those decisions are not always correct or fair. It is important to test these systems carefully and make sure they are being used responsibly rather than assuming that an automated decision is always the right one.
